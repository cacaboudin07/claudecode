# Marketing Digital & IA — Site de présentation

Un site web **tout-en-un** (un seul fichier `index.html`) organisé en
**3 onglets**, qui explique de façon claire et pédagogique le marketing
digital et le rôle de l'IA.

## Contenu

**Onglet 1 — Présentation**
- En quoi consiste le marketing digital (définition)
- Comment il fonctionne (l'entonnoir de conversion)
- Les grands canaux (SEO, Ads, réseaux sociaux, emailing…)
- Le rôle majeur de l'IA

**Onglet 2 — Bien débuter**
- Les 7 étapes pour se lancer pas à pas
- Une boîte à outils gratuits
- Les erreurs classiques à éviter
- Une checklist interactive (progression sauvegardée dans le navigateur)

**Onglet 3 — Ressources**
- Cours & certifications gratuits (Google, HubSpot, Meta…)
- Sites & blogs de référence
- Vidéos & chaînes YouTube utiles

## Aperçu

Site statique moderne et responsive, avec **illustrations SVG** intégrées
(elles s'affichent même hors-ligne), navigation par onglets et animations.

## Lancer le site

Il suffit de **double-cliquer sur `index.html`** pour l'ouvrir dans un
navigateur. Aucun serveur, aucune installation, aucune dépendance.

## Structure

| Fichier      | Rôle                                                     |
| ------------ | -------------------------------------------------------- |
| `index.html` | Tout le site (HTML, CSS, JS et illustrations intégrés)   |
